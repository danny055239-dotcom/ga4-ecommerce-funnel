# GA4 電商購物漏斗分析｜Google Merchandise Store

> 用 BigQuery SQL 分析 Google 官方商店 2020/11–2021/1 約 36 萬個工作階段的 GA4 資料，找出購物流程中流失最多的環節，並提出可執行的改善建議。
>
> 作者：林彧德 Danny Lin｜工具：BigQuery、SQL、Looker Studio
>
> 📊 **互動儀表板：** [Looker Studio](https://lookerstudio.google.com/reporting/ad6f6133-6aa4-4504-81a2-60d4c446cc8a)

---

## 1. 商業問題

Google Merchandise Store 是 Google 的官方周邊電商。資料期間涵蓋黑色星期五、網購星期一與聖誕檔期。這個專案想回答：

1. 檔期前後，整體流量、轉換率與客單價有什麼變化？
2. 使用者在購物流程的哪一步流失最多？
3. 不同裝置、不同來源的轉換表現差多少？購物車放棄率是否有明顯落差？
4. 哪些商品品類「看的人多、加購的人少」？哪些品類貢獻最多營收？
5. 回訪者的轉換率比新訪客高多少？值得投資再行銷嗎？

## 2. 資料

- **來源：** BigQuery 公開資料集 `bigquery-public-data.ga4_obfuscated_sample_ecommerce`
- **內容：** Google Merchandise Store 的 GA4 匯出資料（已匿名化），2020/11/1 – 2021/1/31
- **分析單位：** 工作階段（`user_pseudo_id` + `ga_session_id`），共 360,129 個

## 4. 主要發現

### 4.1 購物漏斗：前段「瀏覽 → 加購」和後段「結帳 → 付款」流失最多

| 步驟 | 工作階段 | 從上一步留下 |
|---|---|---|
| 所有工作階段 | 360,129 | — |
| 瀏覽商品 | 77,020 | 21.4% |
| 加入購物車 | 15,188 | **19.7%** |
| 開始結帳 | 11,106 | 73.1% |
| 填寫付款資訊 | 6,815 | **61.4%** |
| 完成購買 | 4,848 | 71.1% |

- 整體購買轉換率 **1.35%**，購物車放棄率 **68.1%**。
- 看過商品的工作階段，只有 **19.7%** 加入購物車，是前段流失最多的一步。
- 已經開始結帳的工作階段，只有 **61.4%** 填寫付款資訊。這些使用者的購買意圖很強，這個流失比例偏高，是最值得優先改善的環節。

### 4.2 裝置差異小，來源差異大

- 桌機、手機、平板的轉換率（1.30%–1.39%）和購物車放棄率（67.2%–68.7%）都很接近。結帳流失**不是特定裝置的介面問題**，比較可能來自所有裝置共同的因素，例如運費、註冊要求或付款方式。
- 依首次來源比較，**referral（外部網站連結）轉換率 1.66%、購物車放棄率 63.9%，表現最好**；**cpc（付費搜尋）轉換率 0.98%、放棄率 72.9%，表現最差**。referral 的轉換率約是 cpc 的 1.7 倍。

### 4.3 品類：Drinkware 和背包「加購了卻沒買」

- **Drinkware** 瀏覽量第 2、加購率高，但每 100 次加購只賣出約 **5** 件（加購 → 購買 5.15%）。瀏覽量前幾名的其他品類大多在 30–40%。
- **背包** 瀏覽 → 加購只有 **9.94%**（其他品類多在 20–30%），加購 → 購買也只有 **19.5%**，兩段都偏弱。
- **新品標籤（New）** 瀏覽量倒數第二，營收卻排第二，加購 → 購買達 **41.5%**。

### 4.4 檔期：轉換率在網購星期一達到高峰，節後明顯冷卻

- 轉換率從 11 月初逐步上升，黑五（11/27）**【__%】**、網購星期一（11/30）**【__%】** 達到高峰。
- 12/8 工作階段衝到最高（**7.59K**），各來源同步增加，轉換率仍維持在平均以上，推測是全站性活動帶動。
- 聖誕節後工作階段沒有明顯下滑，但轉換率降到全期最低，直到 1 月下旬才回升：使用者持續造訪，但購買意願下降。

### 4.5 顧客：第 4 次造訪後客單價明顯提高

- 加購率和轉換率都是 **常客（第 4 次以上）> 回訪者（第 2–3 次）> 新訪客**。
- 客單價：新訪客 **$68.35**、回訪者 **$69.14** 幾乎相同，常客 **$87.04**，比回訪者高約 **26%**。

## 5. 建議

| 建議 | 對應發現 | 追蹤指標 |
|---|---|---|
| **1. 提早顯示運費、設定免運門檻。** 在商品頁和購物車顯示運費，並提示「再買 $__ 即可免運」；Drinkware 這類低單價商品可以推組合價。 | 結帳 → 付款資訊只剩 61.4%，且各裝置一致；Drinkware 加購後幾乎沒買 | 結帳 → 付款資訊轉換率、Drinkware 加購 → 購買轉換率、客單價 |
| **2. 收斂付費廣告，預算集中在檔期。** 調整 cpc 的受眾與關鍵字，確認廣告和到達頁一致；預算集中在 11 月中到網購星期一，節後低轉換期減少付費廣告。 | cpc 轉換率最低（0.98%）；轉換率在網購星期一達到高峰 | cpc 轉換率、ROAS |
| **3. 把回訪者推向常客。** 對造訪 2–3 次的使用者用會員制度、電子報或再行銷廣告吸引回訪。 | 常客客單價比回訪者高約 26% | 回訪者升級為常客的比例、常客客單價 |
| **4. 背包商品頁做 A/B 測試。** 測試顯示免運門檻、分期付款或更完整的尺寸與容量資訊。 | 背包瀏覽 → 加購只有 9.94% | 背包加購率 |
| **5. 增加新品曝光。** 放到首頁和廣告素材中。 | New 瀏覽量倒數第二，營收排第二 | New 的瀏覽量與營收 |

> 以上原因都是根據資料提出的假設。GA4 資料只看得到在哪裡流失，看不到原因，實際上線時應以 A/B 測試驗證。

## 6. 資料限制

- 資料已匿名化，部分欄位會出現 `<Other>`、`(data deleted)` 等替代值。
- `traffic_source` 是使用者「第一次」造訪的來源，不是每次工作階段的來源。
- 漏斗為開放式漏斗：每一步只看工作階段有沒有觸發該事件，不要求依序完成。
- 品類分析以事件數計算，加購 → 購買比例的分子為售出件數、分母為加購次數，只能當大概的比較，不能直接和漏斗的工作階段比率相比。
- 營收單位為美元，只有三個月資料，無法比較年度趨勢。
